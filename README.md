# AI 照片整理助手第一版

## 当前能力

- 用户主动选择最多 9 张照片。
- 将照片复制到小程序自己的本地用户目录。
- 保存图片尺寸、大小和微信文件摘要。
- 按文件摘要识别完全重复照片。
- 重复组内按分辨率和文件大小给出本地保留建议。
- 用户确认保留照片，其他照片仅标记为“建议清理”。
- 照片库支持预览和移除小程序分析记录。

## 权限边界

- 不会自动读取全部系统相册。
- 不会删除手机系统相册原图。
- “移除分析记录”只清理小程序本地记录和副本。
- AI 分析入口位于 `cloudfunctions/analyzePhotos/index.js`，当前不会上传照片到第三方服务。

## 微信开发者工具

1. 使用 `project.config.json` 中的 AppID 导入项目。
2. 编译并在首页点击“选择照片开始整理”。
3. 若要启用云函数，在开发者工具中开通云开发环境，将 `cloudfunctions/analyzePhotos` 部署为云函数。
4. 接入腾讯云 AI 前，把密钥放在云函数环境变量，禁止写进小程序前端。

## 注意

当前版本的“完全重复”依赖 `wx.getFileInfo` 返回的文件摘要。如果基础库或模拟器没有返回摘要，该照片不会被误判为重复；真机测试时请以实际返回结果为准。
